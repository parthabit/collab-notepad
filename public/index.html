How it works

A realtime collaborative editor with rooms, presence and merge-safe editing.
  • Live sync. Browsers talk to a small Node.js server over WebSockets. Each room is one document, and every change reaches everyone in it within moments.
  • Conflict-safe merging. If two people edit at once, the server does a three-way merge against the revision each client last saw, so both edits survive. The caret is remapped so typing never jumps.
  • Presence. Avatars and typing indicators are kept in memory per room and are not stored.
  • Persistence. Rooms are saved to disk, so a note is still there after a restart.
  • Private library. “Save note” keeps copies in this browser only. Nothing is uploaded.
  • Try it: open this page in two tabs. Shortcut Ctrl/⌘+S saves a note.
